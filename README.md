# LaboratorioCSS - Spa Website

A static website for a spa business, built with HTML and CSS.

## GitHub Pages Deployment

This site is automatically deployed to GitHub Pages using GitHub Actions.

### Deployment Process

- The site is deployed automatically when changes are pushed to the `main` branch
- Manual deployments can be triggered from the Actions tab in GitHub
- The live site will be available at: `https://majoduan.github.io/LaboratorioCSS.github.io/`

### Local Development

To view the site locally, simply open `index.html` in a web browser.

## Structure

- `index.html` - Main HTML file
- `CSS/` - Stylesheets directory
- `img/` - Images directory
- `font/` - Fonts directory
